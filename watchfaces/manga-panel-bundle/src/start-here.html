Thank you for your purchase! Here's how to use your files.

iPhone wallpaper

  1. Save the iphone file to Photos.
  2. Settings → Wallpaper → Add New Wallpaper → Photos.
  3. Pick the image, then tap Add → Set as Wallpaper Pair.

Android wallpaper

  1. Open the android file in Photos or Gallery.
  2. Tap ⋮ → Set as wallpaper.
  3. Choose Lock screen, Home screen or both.

Apple Watch (Photos face)

  1. Save a watch file to Photos on your iPhone.
  2. Open the Watch app → Face Gallery → Photos.
  3. Under Content, choose Photos, select the image, tap Add.

Redmi / Xiaomi watch (Custom face)

  1. Save a watch file to your phone.
  2. Mi Fitness → Device → Watch faces → Online → All → Custom.
  3. Pick a style, choose the image, tap Apply.

Printing the poster

  1. Use the A4-A3 file for A4 or A3 paper, and the 8x10 file for 8×10 in frames.
  2. Print on matte paper (200 gsm or heavier) and choose "Actual size" or "Fit to page".
  3. Print shops and online printers accept these files as they are.

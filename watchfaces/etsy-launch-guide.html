Build the face fileWindows PC · about 1–2 hours the first time

  1. Download and unzip the asset kitDownload Manga-Panel-EasyFace-Assets.zip to your PC and unzip it. There's one folder per colorway. Each has background.png, preview.png, a parts folder and layout.json.
  2. Install EasyFaceFrom github.com/m0tral/EasyFace: install the .msi, install the Visual C++ 2015 x86 redistributable linked there, then copy in the replacement files from the latest release archive. The README says newer watches, including the Watch 5 Lite, need them. Run EasyFace as administrator.
  3. Start a new face for the Redmi Watch 5 LiteChoose the Watch 5 Active/Lite model (410 × 502). Add background.png as the background image and preview.png as the preview.
  4. Add each widget at its positionUse the table below. The numbers are pixels from the top-left corner of the screen. For number widgets, load the 10 digit images (0–9) in order. Right-aligned numbers end at the right-edge value. Name transparent parts with _RGBA and the background with _RGB; the EasyFace wiki uses these suffixes to pick the image format.
  5. Export the .bin and repeat for the other two colorwaysName them manga-panel-classic-ink.bin, manga-panel-sakura.bin and manga-panel-neon-night.bin. The positions are identical for all three, so you can duplicate the project and swap the images.

2

Test on your own watchDon't skip this one

The big unknown. According to the EasyFace README, custom faces reach the watch through a modified Mi Fitness app and an online database. Access to that database is given by Telegram admins, based on your watch's MAC address. I couldn't confirm that a buyer can install a .bin file from Etsy on their own. Find this out before you list. If buyers can't install it themselves, selling files on Etsy won't work as planned.
  1. Join the creator communityThe README sends watch-face creators to a Telegram chat. Contact @mi_watch_int, get the latest Mi Fitness mod (Android only), and ask for editor access. You'll need your watch's MAC address, shown in Mi Fitness → Device → About, or on the watch in Settings → About.
  2. Install your face and use it for a dayCheck that the time, date, weekday, battery, weather, heart rate, steps, calories and stress all update. Check the digits line up, then try all three colorways.
  3. Ask the community how buyers install paid facesAsk exactly this: "Can someone who bought my .bin install it themselves, and how?" Write down every tap.
  4. Finish the buyer guideSend me those exact steps. I'll put them into Step 4 of the install guide PDF and remove the red placeholder box.

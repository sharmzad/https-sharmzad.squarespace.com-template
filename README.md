# Sharmzad - Landing Page Italiana

Landing page in italiano per promuovere il pacchetto combo di Sharmzad Tours a Sharm El Sheikh.

## Pacchetto Combo 80€

Include 6 esperienze:
1. Ras Mohamed via terra
2. Isola Bianca
3. Safari in quad
4. Cammellata nel deserto
5. Giro città & Old Market
6. Farsha Cafe

## Files

- `index.html` - Pagina principale
- `styles.css` - Stili
- `script.js` - Interattività (form, menu mobile, animazioni)

## Utilizzo

Apri `index.html` in un browser, oppure carica i file su un hosting statico o integra il contenuto in Squarespace tramite Code Injection / Code Blocks.

## Personalizzazione

- **Numero WhatsApp**: cerca `201000000000` in `index.html` e `script.js`
- **Email**: cerca `info@sharmzad.com` in `index.html`
- **Immagini**: le immagini hero ed esperienze usano URL di Unsplash; sostituire con foto autentiche di Sharmzad per produzione

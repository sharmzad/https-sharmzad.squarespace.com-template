<script>
  // when user selects an advisor
  const advisorSelect = document.getElementById("advisorSelect");
  const whatsAppBtn = document.getElementById("whatsAppBtn");
  advisorSelect.addEventListener("change", () => {
    const link = advisorSelect.value;
    if (link) {
      whatsAppBtn.href = link;
      whatsAppBtn.style.opacity = "1";
      whatsAppBtn.textContent = "💬 Chat on WhatsApp";
    } else {
      whatsAppBtn.href = "#";
      whatsAppBtn.style.opacity = ".6";
      whatsAppBtn.textContent = "Select an advisor first";
    }
  });
</script>

✨ How it works

The visitor chooses an advisor from the dropdown.

The “💬 Chat on WhatsApp” button automatically points to that advisor’s number.

When clicked, WhatsApp opens with this pre-filled message:

Hi EgTravelMarket! I have a question about the Trip of the Week.

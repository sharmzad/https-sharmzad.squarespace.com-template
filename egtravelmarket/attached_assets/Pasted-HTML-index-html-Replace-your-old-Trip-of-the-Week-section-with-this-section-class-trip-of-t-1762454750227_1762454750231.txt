⚙️ How to Apply on Replit

Open your project on Replit.

Go to index.html, find the old Trip of the Week section, replace it with the HTML above.

Go to styles.css, scroll to the bottom, and paste all CSS above.

Upload the promo image file to Replit’s sidebar.

Copy its exact name (e.g. cairobyflight.jpeg) and replace it in the <img src="...">.

Click Run, refresh preview, and test it on desktop + mobile view.

✅ Result:

Everything fits one screen (no extra scroll).

Text fades in from left, image from right.

Image resizes automatically for tablet & mobile.

Perfect modern alignment for the EgTravelMarket homepage.
